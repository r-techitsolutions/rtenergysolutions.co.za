# R-Tech Energy Solutions Website v2

This version keeps all CSS and JavaScript inside `index.html`, so GitHub Pages cannot lose the styling because of a missing `css/style.css` or `js/script.js` path.

## Upload

Upload these items to the root of your GitHub repository:

- `index.html`
- `logo.svg`
- `images/`
- `CNAME`
- `robots.txt`
- `sitemap.xml`

Do not upload the outer `R-Tech-Energy-Solutions-v2` folder itself. The `index.html` file must appear at the repository root.
