# R-Tech Energy Solutions Website

A static, responsive one-page website for R-Tech Energy Solutions.

## Publish using GitHub Pages

1. Create a new GitHub repository.
2. Upload all files and folders from this project.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public Pages URL.

## Custom domain

In GitHub Pages settings, enter:

`rtenergysolutions.co.za`

Then create the DNS records required by GitHub Pages at your domain provider.
